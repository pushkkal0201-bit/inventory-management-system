 Inventory Management System (C)

Most C projects stop at basic programs.  
This one solves a real-world problem.

This **Inventory Management System** is a fully functional console based application built using C. It helps manage stock efficiently without relying on external databases or frameworks — powered purely by core C concepts.

## What it does
- Add, view, update, and delete inventory items  
- Manage stock with Stock In / Stock Out operations  
- Prevent duplicate item entries  
- Alert for low stock (reorder level)  
- Calculate total inventory value  
- Store and retrieve data using binary file handling  

###  Tech & Concepts Used
- Structures (`struct`) for data
- File handling (`fread`, `fwrite`) for storage  
- Loops & conditionals for logic control  
- String manipulation for input handling  

###  Why this project matters
This project goes beyond syntax and focuses on **real-world problem solving using C**.  
It demonstrates how powerful C can be when applied to practical systems  even without modern tools or databases.
